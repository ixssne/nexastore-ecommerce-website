# NexaStore Spring Boot Project

## Run in IntelliJ IDEA
1. Open the `nexastore-springboot` folder in IntelliJ IDEA.
2. Wait for Maven to finish importing.
3. Run `com.nexastore.NexaStoreApplication`.
4. Open `http://localhost:8080`.

## Notes
- The website UI is the uploaded NexaStore HTML converted into a Spring Boot project.
- The page uses external image/font URLs from the original design.
- No database is required for the current front-end-only demo.
